# SUBLEVEL 9: Free Demo

A first-person 3D horror game that runs in your browser. In 1974 Hollowmere Sanatorium sealed its lowest floor, Sublevel 9. You are Mara Quinn, searching for your missing father, with something in the dark that hates the light.

## What you do
- Find fuses, power the building, and reach the gate.
- Hide in lockers or under beds (hold **Space** to hold your breath).
- Blind the monster with your torch, or tranquilize it with the crossbow (it disappears for about 20 seconds).
- Throw bottles to lure it away.

This demo covers the first two wings (Levels 1-2): the north and middle wings. You need **2 fuses** to power the building, then run for the gate. The south wing, the crossbow safe, the third fuse and the full set of endings are in the full game.

## Controls
| Key | Action |
|---|---|
| WASD / Arrow keys | Move |
| Mouse | Look (if capture is blocked, hold left button and drag) |
| Shift | Sprint (loud) |
| E | Interact / hide / use safe |
| F | Toggle torch |
| Right-click or Q | Flash torch (blinds the monster) |
| 1 / 2 | Torch / crossbow |
| Left-click or Space | Fire crossbow |
| G | Throw bottle |
| Esc or P | Pause / settings |

## Features
Difficulty modes (Easy, Normal, Nightmare), randomised fuse locations and safe code each run, checkpoints, a settings menu (brightness, sensitivity, volume, quality), and a smarter monster that remembers where you hide.

## How to play
1. Unzip the folder.
2. Open `index.html` in Chrome, Edge or Firefox. An internet connection is needed (the game loads three.js from a CDN).
3. Click to start. Headphones recommended.

If the screen stays blank, try Quality: Low in settings, or run a local server: `python -m http.server` and open `http://localhost:8000`.

## Play online with GitHub Pages
Repo Settings > Pages > Deploy from a branch > `main` / root. Your game will be live at `https://<your-username>.github.io/<repo-name>/`.
